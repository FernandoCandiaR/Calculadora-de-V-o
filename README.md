# Calculadora-de-V-o
Protótipo de ferramenta para cálculo de tensão axial em cabos de linhas de transmissão

Desenvolvido por Fernando Candia Ramírez como modernização computacional da formulação apresentada por Rubens Dário Fuchs em Projetos Mecânicos das Linhas Aéreas de Transmissão, incorporando funções hiperbólicas completas, efeitos de vento, variação térmica e interface gráfica em Python.
